# Included dependency

`lib/gson-2.13.2.jar` is Gson 2.13.2, Google's Java JSON library.

- Upstream: https://github.com/google/gson
- Distribution: https://repo.maven.apache.org/maven2/com/google/code/gson/gson/2.13.2/gson-2.13.2.jar
- License: Apache License 2.0, included in `lib/GSON-LICENSE.txt`.
- SHA-256 of the bundled JAR: `dd0ce1b55a3ed2080cb70f9c655850cda86c206862310009dcb5e5c95265a5e0`

The dependency is included so you do not need Maven to run this project. Python dependencies are installed from `python/requirements.txt` and keep their own licenses.
